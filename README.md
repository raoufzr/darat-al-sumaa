
# دارة السمعة — Darat Al-Sumaa

Full-stack Local Reputation Manager SaaS starter.

## Stack
- Next.js 14
- TypeScript
- TailwindCSS
- Prisma
- PostgreSQL
- NextAuth
- Stripe
- Twilio
- Claude AI

## Getting Started

```bash
npm install
cp .env.example .env
docker compose up -d
npx prisma migrate dev
npm run dev
```
